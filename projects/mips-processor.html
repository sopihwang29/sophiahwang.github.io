Overview

For Computing Hardware, I built a working MIPS processor from the ground up. Rather than doing everything in a single clock cycle, a multicycle design splits each instruction into steps, so hardware like the ALU and memory can be reused across steps and each cycle can be shorter.

I wrote the design in SystemVerilog, simulated and debugged it in Vivado, and implemented it on an FPGA.

Fetch. The program counter sends an address to instruction memory, the instruction is read into the instruction register, and the PC moves to the next instruction.

What I worked with

  • SystemVerilog for the datapath and control logic
  • Vivado for simulation, waveform debugging, and synthesis
  • FPGA hardware to run the design for real
