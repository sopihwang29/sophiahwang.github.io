Overview

Matcha Brewer is my final project for Introduction to Computer Science (CS50). It's a full-stack web app for matcha lovers, built with HTML, CSS, Python, JavaScript, SQL, and Jinja templates.

Features

  • User accounts: log in to keep your own drink history
  • Drink log: record new matcha creations
  • Whisking game: an interactive mini-game built in JavaScript
  • Missions: challenges for users to complete
