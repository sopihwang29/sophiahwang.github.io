📄 Read the project report

Overview

Tempo Tiles is a real-time embedded arcade game inspired by Piano Tiles. It uses an Arduino MKR Zero and an ESP32 and integrates physical inputs, LED outputs, audio, and Wi-Fi communication, all written in C++.

The game runs on event-driven logic with careful timing control, score tracking, and real-time user interaction.
