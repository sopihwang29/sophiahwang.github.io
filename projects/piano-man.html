Tempo Tiles

📄 Read the project report

Overview

Tempo Tiles is a real-time embedded arcade game inspired by Piano Tiles. It runs on an Arduino MKR Zero and an ESP32, and ties together physical inputs, LED outputs, audio, and Wi-Fi communication, all written in C++.

What I built

  • Event-driven game logic that responds to player input as it happens
  • Timing control so tiles, lights, and sound stay in sync in real time
  • Score tracking and live feedback for the player
  • Physical interface with buttons, LEDs, and audio output
  • Wi-Fi communication between the hardware and the ESP32
