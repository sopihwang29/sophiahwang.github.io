Overview

Nand2Tetris builds a modern computer from first principles. Starting with a single NAND gate, I worked up through the hardware platform and then the software stack on top of it, using Hack Assembly, Jack, and Python.

The stack, layer by layer

Logic gatesFrom NAND to every other gate
Arithmetic & memoryALU, registers, RAM
CPU & computerThe Hack computer architecture
AssemblerHack Assembly to machine code
Compiler & OSThe Jack language and its libraries

This project is what first got me excited about computer architecture, and it led directly into the MIPS processor I built in Computing Hardware.
